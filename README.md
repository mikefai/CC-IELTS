# IELTS Academic

IELTS Academic prep materials, organized **section → band range → question type**.
Conventions: see `CLAUDE.md` in this folder. Shared quality rules:
`_Shared/CLAUDE-principles.md`.

| Section | Status |
|---|---|
| Listening | Structure only — no materials yet |
| Reading | Band 4–5 all question types; 6–7 MCQ/paragraph mapping; 7–8 mixed matching |
| Speaking | Part 1, band 5–6 |
| Writing Task 1 | Trend/comparative lessons, two-track pack, 2 web apps (`task1-band6-breakthrough`, `ielts-task1-mastery`) |
| Writing Task 2 | Opinion essays, band 5–6 |

Interactive apps: run `npm start` inside the app folder (framework-free, offline-first).
